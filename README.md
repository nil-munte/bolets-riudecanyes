# Bolets de Riudecanyes

Quadern de camp dels bolets comestibles i tòxics que es poden trobar a la zona de Riudecanyes (Baix Camp), pensat per a una primera sortida.

Pàgina: https://nil-munte.github.io/bolets-riudecanyes/

## Avís

Aquest catàleg és orientatiu i no n'hi ha prou per decidir si un bolet es pot menjar. No mengis res que no hagi identificat en persona algú que hi entén. Davant del dubte, no es menja.
